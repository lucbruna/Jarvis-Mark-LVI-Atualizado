# Internationalization (i18n)

Mark LVI uses `core/i18n.py` for translations.

- Locale is read from `JARVIS_LANG` env var or `config/api_keys.json` (`language`/`ui_language`).
- Translation files live in `config/i18n/<lang>.json`.
- Use `from core.i18n import t; t("app.listening")` in code.
- Missing keys fall back to the key itself, so it is safe to call t() anywhere.

To add a language: create `config/i18n/<code>.json` with the same structure as `en.json`.
